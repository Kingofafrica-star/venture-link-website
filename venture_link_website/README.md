# Venture Link Business Consultants Ltd — Website starter

This is a complete, responsive static website starter built from scratch.

## Files
- `index.html` — website content and page structure
- `styles.css` — responsive visual design
- `script.js` — mobile navigation, year display and email enquiry form

## Preview locally
Open `index.html` in a browser. An internet connection is needed for Google Fonts and the remote Unsplash photography.

## Publish with Cloudflare Pages
1. Create a new GitHub repository and upload these files to its root.
2. In Cloudflare, open **Workers & Pages** → **Create** → **Pages** → **Connect to Git**.
3. Select the new repository.
4. For a plain static site, leave the build command empty and set the build output directory to `/` (or `.` if requested by the interface).
5. Deploy and test the generated `pages.dev` URL.
6. Only after approval, attach your existing custom domain or replace the old deployment.

## Before public launch
- Confirm the official office address and business registration details.
- Confirm the exact list of services and any regulatory wording.
- Replace the sample photography with approved company/team/office images if available.
- Connect a real form backend if you want enquiries stored in a dashboard. The current form opens the visitor's email application and does not store submissions.
- Add privacy policy and any legally required company disclosures.
- Test all contact details and links on mobile.
